CHAMOD DILSHAN PORTFOLIO — VS CODE SETUP

Files:
- index.html: website content
- style.css: blue 3D design, responsive layout, footer and smooth scrolling
- script.js: mobile navigation, smooth scroll, active links and reveal animations

Setup:
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Run index.html using the Live Server extension.
4. Put your profile picture in assets/profile.jpg.
5. Put your CV PDF in assets/cv.pdf so the View CV button works.
6. Email and GitHub links are already set to the details provided.

PROJECT CARDS AND DETAIL PAGES
- Click any card in the Projects section to open its own detail page.

- Edit each project page to replace the sample description with your actual project details.
- Use Live Server from index.html to test. The relative links also work when hosted in a subfolder such as GitHub Pages.
